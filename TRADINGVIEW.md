# OB 5★ Scanner — TradingView

Indicateur **Pine v6** aligné sur la logique Kasper 5★ du scanner local (). **Scan only** — pas un conseil financier.

## Installation

1. TradingView → **Pine Editor** → coller le contenu de  → **Save** → **Add to chart**
2. Settings → **Min ★ = 4** (défaut). Ajuster couleurs / mid / labels si besoin.

## Alertes

1. Icône horloge (Alert) → **Condition** = 
2. Choisir une condition :
   -  /  — nouvel OB ≥ Min ★
   -  /  — premier toucher de zone encore fresh
3. **Once Per Bar Close** → webhook / app / email selon besoin  
   ( envoie aussi un message détaillé : symbole, TF, ★, flags, mid)

## Chart suggéré

XAUUSD **M5** ou **M15** (fenêtre paper ICT).

## Note

Les données TV ≠ Coinbase / Yahoo du scanner local → les niveaux peuvent différer.
